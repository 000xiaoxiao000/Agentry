代理节点 · 像素办公室
跨机器新架构：中心就是本应用（agentry），负责监听；远端机器装另一个独立应用 agentry-proxy，它主动连上来、按周期上报各 AI 工具的执行状态，中心据此聚合成「像素办公室」。 两个应用各装各的：远端不需要装 agentry。远端零入站端口，天然穿 NAT / 防火墙。
已接入机器（在线 0 / 共 0）
在远端机器上装 agentry-proxy 即可接入（默认每 5 秒上报一次）。共享密钥两边必须一致。
远端首次配置：agentry-proxy --init --hub <中心>:端口 --secret <密钥> --name <机器名>， 然后直接运行 agentry-proxy；要开机自启加 --install-service。
像素办公室 分类
agentry · 分层架构分析

虚线框内是真正“智能”的部分（可直接复用 Codex harness 的 agent loop）；其余三层（桌面外壳、工具适配层、模型接入） 是把它做成桌面产品时需要补的工程层。右侧的“记忆系统”与“技能/插件”是让工具从“代码 agent”升级为“通用生产力 agent”的关键。
